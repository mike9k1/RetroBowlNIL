# Retro Bowl NIL
NIL enhancement mod for Retro Bowl College 26


This is a mod for Retro Bowl College that aims to improve the game's balancing and add some adjustments that more accurately reflect the modern transfer portal / NIL era.

Current version: v0.0.6


# How to play:

(Note: there are many other ways you can accomplish this - this is simply what I find to be the easiest for end users)

1. Install an extension such as [Resource Override MV3](https://chromewebstore.google.com/detail/resource-override-mv3)

2. Add a redirect for "https://retrobowl26.college/game/rb-college/html5game/RetroBowl.js" to "https://rawcdn.githack.com/mike9k1/RetroBowlNIL/7c93d0d3798b298e700ae349af1ca315e2888f54/RetroBowlNIL_v0.0.6.js"

3. Go to https://retrobowl26.college/online and play the game. The mod will now run in its place. Enjoy!
